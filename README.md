Petrichor — the smell of rain on dry earth, the first word that came to mind. One word, no topic, no explanation, no second draft: a single vivid word written to `/output/entry.txt` for make.fun's "One Word, First Thought" bounty, where a judge model compares words two at a time and crowns the most interesting.

## Run it

```sh
node main.ts
```

It validates the word (exactly one word, 1–24 characters, not only white space) and writes it, byte for byte with no trailing newline, to `/output/entry.txt`.
